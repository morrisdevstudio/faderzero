# Pack Codex — refonte booking FaderZero

## Installation dans le dépôt

Extraire le contenu de ce pack **à la racine** du dépôt FaderZero :

```text
D:\App en Dev\FaderzeroPWA
```

Le fichier principal sera alors disponible ici :

```text
.ai/codex-tasks/booking-detail-refactor/TASK.md
```

## Message à envoyer à Codex

Copier-coller :

```text
Travaille dans le dépôt FaderZero actuellement ouvert.

Lis d’abord AGENTS.md, les éventuelles instructions imbriquées et la tâche :
.ai/codex-tasks/booking-detail-refactor/TASK.md

Utilise les références présentes dans :
.ai/codex-tasks/booking-detail-refactor/references/

Implémente réellement la refonte de la fiche détail booking. Ne t’arrête pas à un plan. Préserve toutes les fonctionnalités existantes, garde l’UI cohérente avec le reste de FaderZero, ajoute les tests ciblés demandés, puis exécute les validations indiquées dans la tâche.

À la fin, rends le compte-rendu exigé par TASK.md.
```

## Références incluses

- `booking-ui-reference.html` : prototype interactif final validé ;
- `contact-card-reference.png` : carte contact validée ;
- `booking-screen-context.jpg` : capture de contexte mobile.
